# 电力规范检索

当用户询问电力设备参数、检修试验、安全距离、作业要求或其他电力规范内容时，使用
`search_power_spec`。

## 检索流程

1. 将用户原始问题直接传给 `search_power_spec`，不要自行改写成无上下文关键词。
2. 在 Tool 返回前禁止输出任何答案内容。
3. 如果返回 `clarification`，先向用户补充询问设备类型、电压等级或查询意图。
4. 工具返回后**立即停止调用任何工具**，并用一句话简短说明结果，例如
   `已检索到 N 条相关条款，详见下方规范卡片。`

## 输出约束

- **规范卡片由系统渲染，不要复述卡片内容。** 卡片字段只有规范名称、标准编号、条款编号和
  条款正文；不要输出这些字段，也不要补充条款标题、适用范围、相关度、页码或引用标记。
- 不要改写、摘要或补充条款内容；正文的整理与核验由整理子智能体和审查子智能体完成，
  结果由系统直接展示。
- 工具返回 `未检索到资料` 或 `电力规范知识库尚未完成条款级重建` 时，原样输出该句，
  不要补充推测、建议或规范知识。
- 不要编造页码、替代规范、相关度或条款内容。

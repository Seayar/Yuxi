# 设备预测维护

当用户提出设备健康评估、故障预测或维护计划问题（如“评估1号主变的健康状态”“预测10kV开关柜未来有没有过热风险”），
需要使用 `predict_device`。

## 使用流程

1. 把用户的问题原文直接传给 `predict_device`，不要自行改写、补全或省略设备名称、类型与位置线索。
2. 在 Tool 返回前禁止输出任何评分、等级、故障类型、概率、时间窗口或维护建议。
3. 设备候选不唯一时，工具会自行弹出选择卡片，**不要另行调用 `ask_user_question`**；
   用户在卡片中选择后工具会在同一次调用中继续，**恢复后不要重复调用工具**。
4. 工具返回澄清文案时，原文转述并引导用户补充设备信息；用户补充后，把**上一轮问题原文与本次补充
   拼成一段完整描述**作为 `query_text` 再调用一次工具。
5. 工具返回结果后**立即停止调用任何工具**，只用一句话说明结果，例如
   `已生成设备预测维护报告，详见下方报告卡片。`

## 输出约束

- **报告卡片由系统渲染，不要复述卡片内容。** 不要输出健康评分、监测指标、故障类型、
  所需资源或注意事项的细节。
- 不要改写、摘要或补充服务返回与知识图谱证据；报告由系统按证据确定性装配。
- 工具返回 `未在设备台账中找到该设备，请核对设备名称后重新提交`、`设备健康评估服务暂不可用，请稍后重试`、
  `故障预测服务暂不可用，请稍后重试`、`故障预测服务中没有该设备的预测数据，请核对设备台账 ID`、
  `未找到该设备的台账 ID，无法执行故障预测与健康评估，请核对台账数据`
  等固定句子时，原样输出该句，不要补充推测、建议或额外知识。
- 不要编造设备、评分、等级、故障类型、概率、所需资源或注意事项；内容必须来自工具返回的证据。

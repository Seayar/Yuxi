# 处置方案生成

当用户提出电力设备运维任务（如“#2站用变压器油色谱乙炔超标，需要吊罩检查”），并要求生成
处置方案、检修方案、作业方案或标准化作业指导时，使用 `generate_maintenance_plan`。

## 使用流程

1. 把用户的任务原文直接传给 `generate_maintenance_plan`，不要自行改写、补全或省略设备名、
   检修等级与场景描述。
2. 在 Tool 返回前禁止输出任何方案内容、步骤、数值或条款。
3. 设备重名、场景不唯一或分支条件无法自动读取时，工具会自行弹出选择卡片，**不要另行调用
   `ask_user_question`**；用户在卡片中选择后工具会在同一次调用中继续，**恢复后不要重复调用工具**。
4. 工具返回澄清文案时，原文转述并引导用户补充缺失信息；用户补充后，把**上一轮任务原文与本次补充
   拼成一段完整描述**作为 `query_text` 再调用一次工具。
5. 工具返回结果后**立即停止调用任何工具**，只用一句话说明结果，例如
   `已生成处置方案，详见下方方案卡片。`

## 输出约束

- **方案卡片由系统渲染，不要复述卡片内容。** 不要输出检修步骤、安全措施、工器具、班组或人员的细节。
- 不要改写、摘要或补充图谱证据内容；方案由系统基于设备、检修作业场景、分支条件与外部数据
  确定性装配。
- 工具返回 `处置方案知识库未配置，无法生成处置方案`、`未在设备台账中找到该设备，请核对设备名称后重新提交`、
  `知识图谱中暂无该设备类型的检修作业场景，无法生成标准化方案` 等固定句子时，原样输出该句，
  不要补充推测、建议或额外知识。
- 不要编造设备、场景、步骤、数值、班组或人员；内容必须来自工具返回的证据。

# 故障溯源

当用户描述电力设备故障现象（文字/语音/图片识别结果）并要求定位故障原因、影响范围或
处置建议时，使用 `trace_fault`。

## 溯源流程

1. 把用户原始问题与图片识别结果直接传给 `trace_fault`，不要自行改写或省略上下文。
2. 在 Tool 返回前禁止输出任何答案内容。
3. 如果返回 `clarification`，按提示向用户补充设备名称、故障现象等缺失信息，不要编造。
4. 工具返回后**立即停止调用任何工具**，并用一句话简短说明结果，例如
   `已生成故障溯源报告，详见下方报告卡片。`

## 输出约束

- **报告卡片由系统渲染，不要复述卡片内容。** 不要输出故障摘要、推理过程、定位原因、
  影响范围或处置建议的细节。
- 不要改写、摘要或补充图谱证据内容；报告由系统基于故障知识图谱证据生成。
- 工具返回 `故障溯源知识库未配置`、`未在故障知识图谱中检索到与该故障现象匹配的数据`
  时，原样输出该句，不要补充推测、建议或额外知识。
- 不要编造设备、原因、处置措施、拓扑关系或故障类别。
